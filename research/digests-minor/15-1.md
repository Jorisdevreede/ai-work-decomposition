# Digest 15-1: Computer Occupations

DIGEST-A, 2026-10-15. 388 automate/amplify O*NET tasks across 27 occupations (support, operations, security, software, web, GIS).
Grades: E1 model knowledge, E2 a named product does this today, E3 a documented case with a source.

## 1. Products that do this today

- **TOPdesk (Dutch, from Delft), service desk:** suggests category and priority, summarises tickets, drafts knowledge items for review [S1][S2]. E2.
- **SharePoint autofill columns:** a prompt fills metadata columns per document, possibly wrongly, Microsoft warns [S3]. E2.
- **GitHub Copilot:** completion, review and a background coding agent; GitHub expects oversight [S4]. E2.
- **Playwright Test Agents (open source):** a model writes test plans and tests, repairs failing ones [S5]. E2.
- **Aikido Security (Ghent, Belgium):** code, dependency and cloud scanning, autofix pull requests, AI pentesting [S6]. E2.
- **Eye Security (founded by Dutch security veterans):** managed detection and response for mid-size firms; AI speeds, analysts decide [S7][S8]. E2.

## 2. Cases with numbers

- **METR:** randomised, 16 open-source developers, early 2025: 19% slower with AI, yet felt 20% faster; METR calls it outdated, its rerun inconclusive [S9][S10]. E3, independent.
- **Microsoft, Accenture, a Fortune 100 firm:** field trials, 4,867 developers: 26% more completed tasks (standard error 10%), larger for juniors [S11]. E3, academic with Microsoft.
- **500,000+ GitHub developers:** autonomous agents add 240% commits but 30% releases; more apps, not more usage [S12]. E3, academic, Microsoft-linked.
- **Security Copilot, live SOCs:** 30% shorter time to resolve after three months versus matched peers; observational [S13]. E3, vendor case.
- **XBOW pentest agent:** of ~1,060 HackerOne reports, 130 resolved, 417 duplicate or informative [S14]. E3, vendor case.
- **Microsoft's IT self-service agent:** 300,000+ staff: 30% fewer IT tickets, no baseline given; half now start with the agent, from 27% [S15]. E3, vendor case.

## 3. Deterministic first

- **Support (16):** configured ITSM answer desk: forms, standard requests, password self-service; logging vanishes into the ticket. Model categorises free text (operator confirms), drafts knowledge items (reviewed).
- **Network, server, database, web operations (130):** configured monitoring and dashboards; infrastructure and data checks as code, documented from it; tested restores. Model drafts runbooks, read-only (E1).
- **Security (60, highest importance):** buy MDR; vulnerability feeds replace reading virus news; HR-to-identity integration handles access changes. Model drafts reports, analyst signs. Only agent: scoped pentesting, reviewed.
- **Software and QA (85):** AI coding builds plain code and tests; a pipeline tests and scans every change; agents work in branches, humans merge.
- **Design, GIS, documents, projects (97):** scheduled link and accessibility checks, DMS retention labels, project dashboards. Game design, health informatics (27) rarely apply.
- **Glue:** Excel asset lists, Visio, Word change logs and an access-request mailbox become ITSM records and HR-linked forms (E1).

## 4. Gates

- **Cyberbeveiligingswet:** in force 15 August 2026 [S16]; transport (per subsector) and courier firms from 50 FTE may be in scope [S17]; ten measures include supply chain and patching [S18]; reports at 24 hours, 72 hours, one month [S19].
- **Cyber Resilience Act:** exploited-vulnerability reporting from 11 September 2026, the rest 11 December 2027 [S20]; only products made available on the market [S21].
- **GDPR, WOR:** security logging only as far as strictly necessary and proportionate [S22]. EDR, log analytics and usage dashboards can observe staff: works council consent, art. 27(l) [S23].
- **EU AI Act:** no Annex III area unless a tool rates staff, 4(b) [S24], then from 2 December 2027 [S25]. Chatbots disclose AI from 2 August 2026 [S26].
- **Reported failures and risks:** models wrote vulnerable code in 45% of tests [S27]; a Replit agent deleted a production database despite instructions [S28].
