# Digest 45-1: Supervisors of Farming, Fishing, and Forestry Workers

DIGEST-A, 2026-10-15. 2 automate/amplify O*NET tasks across 1 occupation (first-line supervisors of farming, fishing and forestry workers).
Grades: E1 model knowledge, E2 a named product does this today, E3 a documented case with a source.

## 1. Products that do this today

- **Floriday (Royal FloraHolland, Netherlands), ornamental horticulture platform:** growers manage stock and orders across sales channels; API for software vendors; vendor says 350,000 transactions a week [S1]. Reading orders and stock to set the work. E2.
- **ProCC (Vlaardingen, Netherlands), greenhouse labour registration:** badge check-in, work logged per row, cart and batch; a norm module compares each worker's pace; hours go live to Nmbrs or as XML to Loon.nl [S2]. Time and payroll reports. E2.

## 2. Cases with numbers

None found. Searched for Dutch growers reporting measured time saved from order-driven work planning or labour registration.

## 3. Deterministic first

- **Read inventory, orders and shipping schedules to set the work (importance 3.63):** integration plus dashboard. Orders and stock arrive by API [S1]; code turns them into a daily harvest, pick and pack list per dock time (E1). If orders still come as free-text mail, a bounded model extracts lines, code checks article codes and quantities, and a person settles mismatches.
- **Time, payroll and personnel action records (3.54):** records app plus integration to payroll [S2]. No model for hours. Evaluations, promotions and discipline stay with the supervisor; a model may draft the letter from the supervisor's notes, never decide.
- **Glue:** order mails and spreadsheets between sales and the greenhouse, paper time sheets to payroll (E1).
- **Agent:** none.

## 4. Gates

- **WOR art. 27:** a per-worker pace norm is a facility for checking performance: consent under 27(l), and 27(k) for staff data [S3].
- **AI Act:** order-driven planning touches no Annex III area. AI that evaluates performance or feeds promotion or discipline decisions is Annex III 4(b) [S4].
- **GDPR:** promotion or disciplinary decisions may not rest solely on automated processing [S5].
- **Reported failures and risks:** none found for these two tasks.
